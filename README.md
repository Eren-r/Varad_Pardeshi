## 🔥 2. ThermoSentinel-AI

**Satellite Data • NASA FIRMS • Geospatial AI • Risk Intelligence • Machine Learning**

An AI-assisted thermal anomaly intelligence platform designed to investigate **persistent and potentially high-risk thermal activity** using satellite observations and geographic context.

### Core pipeline

```text
NASA FIRMS / VIIRS
        ↓
Thermal Anomaly Collection
        ↓
Event Grouping
        ↓
Temporal & Spatial Features
        ↓
OpenStreetMap Context
        ↓
Risk / Persistence Analysis
        ↓
AI Classification
        ↓
GIS Decision Dashboard
```

### Current work

* NASA FIRMS historical data processing
* Thermal event detection
* Multi-observation event grouping
* Multi-day persistence analysis
* Recurrence analysis
* FRP-based features
* OpenStreetMap contextual features
* Distance-to-context measurements
* Historical event analysis
* Feature engineering
* Activity-aware FIRMS query planning
* Resumable data acquisition pipeline

### Key engineering challenges

* Thermal anomaly ≠ confirmed industrial fire
* Satellite observation gaps
* Cloud / observation limitations
* Spatial resolution constraints
* Limited labeled data
* False positives
* Intermittent activity

The project therefore focuses on **evidence aggregation and risk intelligence rather than treating every thermal anomaly as a confirmed incident**.

**Repository:**
👉 https://github.com/Eren-r/ThermoSentinel-AI

**Status:** 🚧 Active Development
